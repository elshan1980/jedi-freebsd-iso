# Sith Project (based on jedi-freebsd-iso)

**Target Hardware:** Lenovo LOQ 15IRX9 (Intel i7-13650HX / RTX 4050 / 24GB RAM)
**Base OS:** FreeBSD 15.0-RELEASE

### Features:
* **No Remote Access:** SSH is disabled out of the box (Security first).
* **Hybrid Graphics:** Pre-configured for Intel UHD & Nvidia Ada Lovelace.
* **Optimized Kernel:** Tuned for 14-core Raptor Lake architecture.
